# Bug Log

> 项目 bug 记录本。
>
> 定位方法参考 `docs/BUG_CLASSIFICATION.md`。每次遇到 bug，按下方模板追加一条记录。
>
> 记录目的：
> - 帮助非技术人员也能追踪问题
> - 方便 AI 快速理解上下文
> - 长期统计哪个模块最容易出问题

---

## 模板

```markdown
### YYYY-MM-DD - 一句话概括问题

- **现象**: （你看到了什么）
- **模块猜测**: （Fetcher / Summarizer / Classifier / Dedup / Scorer / Knowledge / Embeddings / Reporter / Frontend / Database / Config / Pipeline）
- **影响范围**: （全部 / 某个来源 / 某篇文章 / 某个页面）
- **频率**: （必现 / 偶发 / 定时）
- **证据**: （截图 / 日志 / 输入输出样本 / 报错信息）
- **决策**: （立即修 / 延后 / 绕过 / 需要更多信息）
- **处理结果**: （后续补充）
```
